<h1>Pack Out</h1>
<h2>Summary</h2>
<p>Pack Out is an educational program developed in Qt to teach about safety and preparation in the wilderness.</p>
<h2>Features</h2>
<p>
  Pack Out features five levels exploring popular hikes around the world.
  Each level starts with a description of the hike, and what gear you might need to pack.
  You then must pack your bag appropriately, and go on the hike via a fun minigame. 
  Once completed, you will receive a grade on how prepared you were for the hike. 
  Depending on your grade, you will either move on, or retry the level. 
</p>
<h2>How to Run</h2>
<p>
  To play Pack Out, go to the release page of the git hub repository, and download "Pack_Out_Runnable.zip".
  Unzip it, open the unzipped folder and run "Pack_Out.exe"
</p>
<p>
  Additionally, you can clone this project into Qt Create, and run the program there. 
</p>
